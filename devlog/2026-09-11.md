## 备注

- **教训：批处理（.bat）文件里不能写中文**。cmd.exe 按系统默认代码页（中文系统是 GBK）解析文件内容，UTF-8 保存的中文会字节错位，把脚本搅乱（实测现象：`echo` 后面的中文被拆成命令、报「不是内部或外部命令」）。正确做法：**bat 内保持纯 ASCII，中文提示交给 Node 脚本输出**（Node 输出 UTF-8，配合 bat 首行 `chcp 65001` 在黑窗口里显示正常）
- 用 git bash 测试双击效果不可靠：`cmd //c <中文文件名>` 与含中文的参数都会因编码转换失败（这属于测试工具的坑，不代表用户双击会失败）。可靠的测试姿势：复制成 ASCII 名的副本，用 `powershell -Command "& '.\_launch_test.bat'"` 运行
- 自检教训 5：**页内 `location.reload()` 会被我们的安全设置 `will-navigate` 拦截**（这是正确行为），要重载界面必须用主进程的 `webContents.reload()`
- 自检教训 6：渲染层的卡片列表是启动时的一次性缓存，自检中途通过 IPC 建的卡主页看不到——建完卡要重载界面再驱动 UI（真实用户走编辑器页面会刷新缓存，不受影响）
- 自检教训 7：自检如果想验证「请求真的发出去了」，别只看 mock 记录的请求体——先确认全局设置指向了 mock 地址与 Key，否则读到的可能是上一轮的旧记录（本轮就因此误判过一次）
- 自检教训 8：用 native setter 给 `<select>` 设值时，**值必须是下拉里真实存在的 option**，否则浏览器会把 value 归空、React 读到空串——想验证自定义模型名要走「自定义…」+ 输入框那条路径
