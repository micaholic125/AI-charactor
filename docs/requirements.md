# 需求文档

> 本文档是产品需求的唯一权威来源。需求有疑问时以本文档为准；需求变更需先修改本文档，再动代码。
> 最后更新：2026-09-19

## 1. 项目简介

「AI 聊天卡」是一款运行在 Windows 上的 AI 角色聊天软件。用户把**系统提示词（人设）**与**世界书（世界观）**保存成一张张聊天卡，点开卡片即可与 AI 角色进行多轮对话。目标用户是不懂技术的普通用户，UI 要求简洁直观。

## 2. 核心概念

| 概念 | 说明 |
|---|---|
| 聊天卡 | 一个可聊天的角色/场景配置，包含：名称、头像、系统提示词（人设）、开场白（可选）、世界书、模型（可选，不填用默认）、输出方式（可选，不填用默认） |
| 世界书 | 世界观设定集合。每条设定包含标题、内容、触发关键词（逗号分隔）、排序、是否常驻。聊天中命中关键词的条目会自动注入 AI 的上下文 |
| 对话 | 与某张卡的独立聊天会话，一张卡可开多个对话 |
| 聊天分支 | 以某个对话里某条 AI 回复为终点**复制**出来的新对话。之后两边各聊各的，互不影响；只在标题和出处上留个记号。见 3.4 |
| 供应商 | 一组 API 接入配置（**名称（可选）** + 接口地址 + API Key + 默认模型 + 可用模型列表 + **常用模型**）。可保存多条随时切换，**以接口地址为标识**；名称只用于显示。见 3.7 |
| 可用模型列表 | 从供应商那里一次性拉回来的、这家接口支持的全部模型名（已滤掉不能聊天的），存在本机随时选，不用每次重拉。可从里面挑出几个**常用模型**，挑过之后聊天页只列这几个 |
| 常用模型 | 从某条供应商的可用模型列表里挑出来的少数几个模型（也可手动填列表外的名字）。聊天页切换模型时只列它们，用来对付「一家接口下模型太多」的情况。一个都没挑过 = 照旧列全部 |

## 3. 页面结构与功能需求

### 3.1 底部导航
应用底部固定三个栏目：**主页**、**我的**、**API 配置**。

### 3.2 主页
- 罗列所有已保存的聊天卡（网格布局）
- 顶部搜索框：按名称搜索聊天卡
- 每张卡可收藏（心形按钮切换）到「我的收藏」
- 「+ 新建」入口：创建聊天卡
- 「导入」按钮：从 JSON 文件导入聊天卡
- 点击卡片进入该卡的对话列表页

### 3.3 我的
包含两个子栏目（分段切换）：

**我的收藏**
- 展示已收藏的聊天卡
- 支持：置顶/取消置顶、移出收藏（删除）、搜索

**游玩历史**
- 在某张卡的任意对话中发出第一条用户消息时，该卡自动收录
- 每次聊天更新「最近游玩时间」
- 支持：置顶/取消置顶、移出历史（删除）、搜索

> 收藏/历史中的「删除」仅将该卡移出对应列表，**不删除卡片本体**。卡片本体的删除在卡片编辑页进行。

### 3.4 聊天
- 进入卡片后可见对话列表（对话标题、相对时间），可新建对话、重命名对话、删除对话
- 聊天界面：多轮对话（AI 记忆上下文），AI 回复流式逐字显示（打字机效果）
- 生成中发送按钮变为「停止」，可中断（半截回复保留）
- 对话记录保存在本机，重启后自动继续上次对话
- 首次在卡内发出用户消息 → 自动收录进游玩历史
- **聊天界面顶部有状态条**，显示当前生效的**供应商 + 模型名 + 输出方式**（供应商起过名称就显示名称，没起名就显示接口地址），点击可当场切换供应商与模型、切换流式/非流式
  - 改完立即对**后续发送**生效（正在生成中的那条回复不受影响）
  - **切换供应商是全局的**：影响所有卡片与对话（后续消息走新地址与 Key）
  - **切换模型只影响这张卡**：同卡的其他对话、以及别的卡片都不受影响；下次打开这张卡仍然是你选的那样
  - 未设置过的卡跟随全局默认（当前供应商的默认模型 + 设置里的默认输出方式）
  - 这是「试错」入口：聊着发现这个模型不好用、或逐字输出被服务商过滤，不用退出去翻设置，就地换掉继续聊
- **状态条浮层里能一次看到全部家底**：按供应商分组，组标题显示这条供应商的**名称**（没起名就显示接口地址），标题下列出它的**模型**；点某个模型即「这家 + 这个模型」一起用上（供应商随之全局切换）
  - 挑过「常用模型」的供应商**只列挑过的那几个**（解决办法：接口下模型太多、翻起来费劲）；一个都没挑过则照旧列出全部
  - 浮层里**不给**手动输入模型名的入口——要手填一个列表外的模型，去「API 配置」里编辑那条供应商
  - 当前这家挑过常用模型时，浮层里给一句灰字说明：「这条供应商只显示你挑的常用模型（{N} 个）；想改就去「API 配置」里编辑它」
  - 所以换模型不限于当前这家：从 A 家的甲模型换成 B 家的乙模型，一次点击即可
  - 某家还没获取过模型列表时，该组下方给一句提示，引导去「API 配置」里获取
  - 若切换后这张卡原先单独指定的模型在新家不存在，自动改回新家的默认模型并提示一句（避免必然失败的请求）
  - **取消本卡指定**：再点一下当前打勾的那个模型即可，回到「跟着供应商的默认模型走」——浮层里不出现「用默认模型」「自定义模型」这类多余选项
  - 若这张卡指定过一个**不在显示列表里**的模型（早前手填的、旧数据、或被常用模型过滤掉的），仍要在当前供应商那组里把它显示成一行并打勾，挂「本卡指定」小标签，点一下同样是取消指定；这条供应商的默认模型若不在常用模型里，也一样要显示出来（挂「默认」小标签）
  - 总之：**当前生效的那个模型永远看得见，且任何状态下恰好只有一行打勾**
- **每条消息都能改**（鼠标移到气泡上才浮出操作条，平时界面干净）
  - 自己发的话：**修改**、**撤回**、**复制**
  - AI 说的话：**创建新聊天分支**、**修改**、**重新输出**、**删除**、**复制**
  - 「修改」= 就地把气泡变成输入框改文字。改 AI 消息只改这一条；改自己发的话要问一句「后面的内容怎么办」
  - 「撤回」= 删掉这条和它引出的那条 AI 回复，**文字放回输入框**，可以改一改再发
  - 「重新输出」= 让 AI 对这一轮重新回答。可以「后面的内容一并删掉重来」，也可以「只重写这一条，后面的留着」
  - 「删除」= 删掉这条，或这条及之后全部
  - 「创建新聊天分支」= 以这条 AI 回复为终点**复制出一个新对话**，之后在新对话里接着聊；原对话原封不动。新对话出现在这张卡的对话列表里，标题带「· 分支」
  - 删掉中间某条时若有后续内容会一并消失，**动手前一律弹窗确认，并写清会连带删掉几条**
  - 正在生成回复时这些按钮不可用

### 3.5 卡片编辑
- 字段：名称、头像（本地图片，>5MB 拒绝）、开场白、角色设定（系统提示词）、模型（可选）
- 模型为下拉选择：列出**当前使用中那条供应商的可用模型**（已获取过的），列表外的模型可手动输入；不选 = 用这条供应商的默认模型
  - 这里列出的是**全部**可用模型，不跟随「常用模型」过滤——常用模型只收窄聊天页的切换列表，编辑卡片时仍然能选到任何一个
  - 想用别家的模型，先到「API 配置」或聊天页状态条把供应商切过去（切换供应商是全局的事，不该由改一张卡来顺手改变）
- 模型在编辑页和聊天页状态条都能改（同一份数据）；输出方式的卡片级开关只在聊天页状态条上
- 世界书编辑：条目列表（标题、关键词、常驻标记、排序上移/下移、编辑、删除）+ 添加条目
- 保存 / 删除卡片（删除需确认，连带删除其全部对话与头像）
- 未保存修改时返回需确认

### 3.6 设置
- 温度（0–2）、最大生成长度（maxTokens）
- **接收方式**（全局默认）：流式（AI 回复逐字显示，默认）或非流式（回复一次性整段返回）。若服务商对逐字输出做了过滤、或流式经常被截断，可切换为非流式规避
- 设置保存在本机
- 接口地址、API Key、模型**不在本页**，已移到「API 配置」栏目（见 3.7）；「测试连接」也随供应商管理一起移过去

### 3.7 API 配置
与「主页」「我的」同级的独立栏目，用来管理多个**供应商**（服务商）配置：
- **供应商** = 一组 API 接入信息：**名称（可选）**、接口地址（baseUrl）、API Key、默认模型、**可用模型列表**、**常用模型**。**以接口地址作为唯一标识**；名称只用于显示，可以随便起
- 列表页：罗列已保存的供应商，主文字显示名称（没起名则显示接口地址；有名称时接口地址以灰色小字跟在后面）、默认模型、常用/全部模型数、Key 是否已填；当前正在使用的那条有「使用中」标记
- **名称（可选）**：给这条配置起个好记的名字（例如「DeepSeek 官方」）。只用于界面显示——列表页、删除确认、聊天页状态条、模型浮层的分组标题都用它；**不影响接口地址，也不参与去重与合并**（地址仍然是这条配置的身份）
- **常用模型**：从拉回来的可用模型列表里挑出几个常用的；也能手动填一个列表里没有的模型名（有些服务商不提供模型列表接口，或者想要的模型被自动过滤掉了）。聊天页的模型浮层**只列挑过的这些**；一个都没挑过则照旧列全部
  - 挑选结果单独存放，**不裁剪可用模型列表**：重新「获取模型列表」不会冲掉已经挑好的常用模型
  - 列表里已经下线的名字、手填的名字会保留并标记出来（「不在列表里」），方便随时清理
- 可**新建**、**编辑**、**删除**供应商；每条可单独「测试连接」验证是否可用
- **一键获取模型列表**：填好接口地址与 API Key 后，点「获取模型列表」即可从服务商拉回这家支持的全部模型名（走 OpenAI 兼容的 `/models` 接口）
  - 拉回来的列表**自动存在本机**（每条供应商各存各的），之后聊天里换模型直接用，不必每次联网重拉
  - 保存这条供应商时会顺带自动拉一次（拉失败不拦保存，只提示一下）
  - 自动**滤掉不能聊天的**（向量 embedding、语音合成、语音识别、画图、重排、审核等）；万一有想要的被滤掉了，还能手动输入模型名
  - 拉不到（服务商没提供这个接口、Key 没填对、网络不通）时给出中文说明，并可随时重试；此时仍能手动输入模型名照常使用
- **切换使用中的供应商**：在列表里点一下即切换（也可在聊天页状态条就地切换），全局生效——之后所有聊天请求都走新供应商的地址与 Key
- 新建时可点常见服务商快捷按钮（DeepSeek / Kimi / 智谱 / 通义）自动填好地址与模型
- 首次从旧版本升级时，把原有的接口地址 / API Key / 模型自动转成第一个供应商，用户不用重填

### 3.8 导入 / 导出
- 导出：把聊天卡（含头像，内嵌 base64）导出为单个 JSON 文件
- 导入：支持多选 JSON 文件批量导入

## 4. API 接入

- 仅支持**通用 OpenAI 兼容接口**（chat/completions 格式），覆盖 DeepSeek、Kimi(Moonshot)、智谱 GLM、通义千问、OpenAI 官方等
- 全局配置中定「当前供应商」（接口地址 + Key + 默认模型 + 可用模型列表，见 3.7）与「默认输出方式」（见 3.6）；每张卡可单独指定模型与输出方式（未指定用默认），指定入口为编辑页（模型）与聊天页顶部状态条（模型 + 输出方式）；用户自备 API Key
- 聊天页顶部状态条可直接切换**当前供应商**（全局生效）与这张卡的模型 / 输出方式（只影响这张卡）；切换供应商与挑模型合并成一个「按供应商分组的模型列表」，点一个模型即同时定下「哪家 + 哪个模型」
- 可用模型列表通过 OpenAI 兼容的 `GET {接口地址}/models` 获取（见 3.7）

## 5. 非功能需求

| 类别 | 要求 |
|---|---|
| 平台 | Windows 10/11，Electron 桌面应用，打包 NSIS 安装包 + 便携版 exe |
| 数据 | 全部保存在本机（%APPDATA%\ai-chat-cards），无任何云端上传（API 请求除外） |
| 语言 | 界面、文档、日志全部中文 |
| 错误提示 | 面向新手的中文提示（401→密钥无效、404→地址/模型错误、网络不通等） |
| 主题 | 跟随系统浅色/深色自动切换 |
| 稳定性 | 数据写入采用原子写（临时文件+重命名），中断/退出不损坏数据、不丢失已生成文本 |
| 安全 | 渲染层沙箱隔离（contextIsolation + sandbox），仅暴露白名单 API（window.api） |
| 依赖 | 零原生模块（不需安装 Visual Studio 构建工具），npm install 一次通过 |

## 6. 明确不做（未来工作）

- AI 回复的 Markdown/LaTeX 渲染（当前纯文本）
- 超长对话的上下文自动截断
- 卡片的市场/在线分享平台
- 多账号、云同步
