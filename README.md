# AI 聊天卡

一个 Windows 桌面 AI 角色聊天应用。把「系统提示词（人设）+ 世界书（世界观）」保存成一张张**聊天卡**，点开即可与 AI 角色聊天。

当前版本：**1.0.0**

- 🎴 聊天卡：人设、开场白、世界书、图片头像，支持导入/导出分享（本应用格式 + Dify 格式）
- 💬 多对话与分支：每张卡可开多个独立对话，任意一条 AI 回复都能「建分支」另起一条时间线
- ⌨️ 流式打字机回复：文字边生成边显示；中途停止保留半截回复；消息可修改 / 撤回 / 重新输出 / 删除
- 🧠 三层记忆（短期 / 长期 / 永久）：AI 自动把长对话整理成记忆，久远内容不会丢；记忆页可手动增删改，改旧消息时可选是否同步修正记忆
- ⚙️ 每张卡可单独调温度与回复长度；聊天页按供应商分组切换模型
- ⭐ 收藏 / 🕘 游玩历史：可置顶、可删除、可搜索
- 🔌 自备 API：兼容任意 OpenAI 兼容接口（DeepSeek、Kimi/Moonshot、智谱 GLM、通义千问、OpenAI 等）
- 🌗 界面跟随系统浅色/深色，全部数据保存在本机

## 安装与运行

### 方式一：安装包（推荐）

1. 双击 `release\AI聊天卡-Setup-1.0.0.exe`
2. 一键安装（不需要点下一步），自动创建桌面快捷方式
3. 以后双击桌面的「AI聊天卡」图标即可打开

> 应用没有做数字签名，首次运行时 Windows SmartScreen 可能提示「Windows 已保护你的电脑」——点「**更多信息 → 仍要运行**」即可。

### 方式二：便携版（免安装）

双击 `release\AI聊天卡-1.0.0-便携版.exe` 直接运行，不会写注册表。首次启动会先解压，比安装版慢几秒，之后正常。

> 便携版只是「免安装」，数据仍然保存在 `%APPDATA%\ai-chat-cards\`（和安装版共用一份数据）。

### 方式三：从源码运行（开发用）

- Windows 10/11
- Node.js **22.12 或更高版本**
  - 官网：https://nodejs.org （选 LTS 版本）
  - 国内镜像站：https://npmmirror.com/mirrors/node/ 或 https://nodejs.cn

**第一次使用**（只需做一次，约几分钟）：

```bash
npm install     # 安装依赖（已配置国内镜像）
```

**以后每次启动应用**：双击项目根目录的 **`启动AI聊天卡.bat`**，等十几秒就会弹出应用窗口。

- 启动时会同时出现一个**黑色命令行窗口，它不能关**——关掉它应用会一起退出
- 退出应用：先关应用窗口，再关那个黑色窗口
- 想确认是不是卡住了：黑色窗口里有中文提示；启动失败时也会把原因写在那里，截图发给 AI 助手即可

> 熟悉命令行的话，等价于在项目目录执行 `npm run dev`。

## 常见问题

**`npm run dev` 报错 `Electron uninstall`**
依赖安装时 Electron 二进制可能被 npm 安全策略拦截，手动补下载即可：

```bash
node node_modules/electron/install.js
```

**打包时 electron-builder 报错、提示缺少二进制**
多数情况是打包用的 Electron / NSIS 压缩包没下载成功。确认 `.npmrc` 里的 `electron_builder_binaries_mirror` 仍在，然后重试 `npm run build:win`。

## 国内网络说明

项目根目录的 `.npmrc` 已配置国内镜像（npmmirror），安装依赖和打包时不会卡住。如果你不在国内或镜像异常，删除该文件即可恢复官方源。

## 数据存储位置

所有数据（卡片、对话、记忆、设置、头像）保存在：

```
%APPDATA%\ai-chat-cards\
```

卸载应用**不会**自动删除这些数据；想彻底清除，手动删除这个文件夹即可。

## 已知限制

- **AI 回复按 Markdown 排版**（加粗 / 斜体 / 标题 / 列表 / 表格 / 引用 / 代码块等）；**数学公式（LaTeX）暂不支持**
- 回复里的链接显示成蓝色但**点了没有反应**、图片**不显示**（有意设计：AI 给出的网址可能是它自己编的，避免点到可疑网站）。自己打的字保持纯文本
- 中途停止生成的半截回复会保留为消息（有意设计）
- **记忆系统会额外调用 AI**：大约每 6 条新消息触发一次后台总结，短期记忆满 25 条时再沉淀一次；这些请求同样计入 API 费用。自动整理失败不影响聊天，记忆页会显示原因并可重试
- 记忆按对话保存，**不同对话之间不共享**；删除对话会连同它的记忆一起删除
- 有些角色模型不会按约定写记忆标记，这时靠「兜底总结」补上，功能不受影响，只是便宜路径少生效
- **导入**认得两种文件：本应用导出的卡，以及 **Dify 格式的卡**（`model_config` 结构，很多同类平台用它）。Dify 的 YAML（DSL）导出暂不支持
- 有些平台导出的卡里**提示词和世界书是空的**（平台导出时就没下发），导入报告会明确提示——那不是本应用弄丢的，需要自己补写
- **不提供从站点抓取 / 批量下载卡片的功能**：只导入你自己选中的文件
- 卡级生成参数目前只有**温度**与**最大长度**两项；`Top-P`、`Top-K`、存在惩罚、频率惩罚等会陆续加上
- 超长对话会占用较多 token，可能触及模型上下文上限（记忆系统会缓解，但记忆本身也有容量上限）
